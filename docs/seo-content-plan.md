## 2. AEO (Answer Engine Optimization) Direct-Answer Framework
For AI search engines (Google AI Overviews, Perplexity, ChatGPT Search, Claude Search, Apple Intelligence), every medical page must adhere to the **Direct-Answer Rule**:
1. **Immediate Answer (40–60 words):** Placed directly below the H1 heading. Uses precise definitions, clinical indications, and local geography without introductory filler.
2. **Question-Format Headings (H2/H3):** Matches exact patient query syntax (e.g., *"What is the recovery time after laparoscopic hysterectomy?"*).
3. **Structured Tables & Bullet Lists:** Clear data points for symptoms, comparison of options, and recovery timelines.
4. **Author Credential & Review Date Line:** *"Medically written / reviewed by Dr. Mudita Jain Talesra (MS, FMAS, FICOG). Last updated: November 2026."*
5. **Schema Synchronization:** Exact word-for-word parity between visible text and JSON-LD `FAQPage` and `MedicalProcedure` schema markup.
